# Reporting and Scoring

## 1. Report Purpose

The report transforms raw compliance results into an understandable assessment.

## 2. Report Sections

A report should contain:

1. Overall score
2. Executive summary
3. Category scores
4. Passed checks
5. Failed checks
6. Warnings
7. Evidence
8. Recommendations
9. Limitations
10. Scan metadata

## 3. Category Scores

Initial categories:

- Consent & UI
- Network & Tracking
- Security & Transport
- Privacy Policy
- Data Subject Rights

## 4. Individual Finding

Each finding should contain:

- Check ID
- Check name
- Result
- Severity
- Confidence
- Evidence
- Explanation
- Recommendation

## 5. Scoring Principle

The system should not reduce all checks to a simplistic binary legal-compliance statement.

The score should represent the automated assessment performed by the crawler.

The report should clearly identify:

- Deterministic findings
- Heuristic findings
- Undetected information
- Non-crawlable requirements

## 6. Legal Disclaimer

The system should communicate that automated assessment does not constitute a complete legal GDPR determination.
